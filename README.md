## Introducción
Python es un lenguaje de programación ampliamente utilizado en diferentes áreas de la tecnología, especialmente en Ciencia de Datos. Cuenta con funciones incorporadas que permiten realizar operaciones, manipular información y desarrollar programas de manera sencilla.

En este documento se presentan diez funciones básicas de Python, explicando su utilidad y mostrando ejemplos prácticos para comprender su funcionamiento.

## Objetivo
Investigar y aplicar las funciones básicas de Python usando ejemplos prácticos, siendo prioridad identificar su utilidad en la programación y su aplicación en el manejo de datos.
