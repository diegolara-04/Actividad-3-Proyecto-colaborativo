## Introducción
Python es un lenguaje de programación ampliamente utilizado en diferentes áreas de la tecnología, especialmente en Ciencia de Datos. Cuenta con funciones incorporadas que permiten realizar operaciones, manipular información y desarrollar programas de manera sencilla. 
En este repositorio se mostrarán las funciones básicas de Python, explicando su utilidad y proporcionando ejemplos prácticos para comprender su funcionamiento.


## Descripción del proyecto

Este proyecto tiene como finalidad investigar y documentar 30 funciones básicas del lenguaje de programación Python, explicando su funcionamiento mediante ejemplos prácticos.
Se busca fortalecer los conocimientos básicos de programación y desarrollar habilidades en el uso de herramientas colaborativas.

## Objetivo general

Investigar y aplicar 30 funciones básicas de Python, comprendiendo su utilidad mediante ejemplos prácticos y utilizando GitHub como herramienta de trabajo colaborativo.
